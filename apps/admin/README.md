# 🍱 런치캐치 · 관리자 앱

> 운영자가 LLM으로 포스터 템플릿을 만들어 게시하고, 캠페인과 회원, 정산, 부정 사용을 관리하는 백오피스

## 주요 화면

| 화면 | 주소 | 설명 |
| --- | --- | --- |
| 템플릿 관리 | `/templates` | 임시저장 중이거나 게시된 템플릿 목록과 iframe 미리보기, 게시와 활성화 관리 |
| 템플릿 만들기 | `/templates/new` | 채팅으로 LLM에 요청해 포스터 템플릿 HTML 생성·수정, 버전별 임시저장 |
| 대시보드 | `/dashboard` | 서비스 지표와 추이 |
| 캠페인 관리 | `/campaigns` | 점주 캠페인 확인 |
| 심사 관리 | `/reviews` | 점주 입점 신청 심사 (준비 중) |
| 회원 관리 | `/members` | 사용자와 점주 회원 조회 |
| 포인트 · 정산 | `/settlements` | 포인트 결제와 정산 내역 |
| 부정 관리 | `/fraud` | 부정 사용 의심 캠페인과 회원 조치 |
| 관리자 계정 | `/admin-accounts` | 관리자 계정 발급과 관리 |

## 폴더 구조

```
src/
├── app/            # 라우터
├── pages/          # 주소 하나에 대응하는 화면
├── features/
│   ├── login/          # 관리자 로그인
│   ├── template/       # 템플릿 채팅 생성, 미리보기, 관리
│   ├── dashboard/      # 대시보드
│   ├── campaign/       # 캠페인 관리
│   ├── member/         # 회원 관리
│   ├── billing/        # 포인트 · 정산
│   ├── fraud/          # 부정 관리
│   └── admin-account/  # 관리자 계정
├── components/     # 여러 기능이 함께 쓰는 컴포넌트
├── hooks/          # 여러 기능이 함께 쓰는 훅
├── layout/         # 사이드바 레이아웃
├── api/            # 서버 요청 함수와 mock 데이터
└── auth/           # 로그인 상태와 접근 제어
```
