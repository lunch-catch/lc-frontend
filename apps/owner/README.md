## 주요 화면

| 화면 | 주소 | 설명 |
| --- | --- | --- |
| 로그인 · 입점 신청 | `/login`, `/signup` | 약관 동의, 가게 정보와 위치, 영업시간, 가게 이미지, 대표 메뉴 등록 |
| 홈 | `/home` | 진행 중인 캠페인과 최근 성과 |
| 캠페인 | `/campaigns`, `/campaigns/ended` | 진행 중·예정 캠페인과 지난 캠페인 목록 |
| 캠페인 등록 | `/campaigns/new` | 쿠폰 조건, 노출 대상, 하루 예산과 기간 설정, 템플릿으로 포스터 제작 |
| 캠페인 상세 | `/campaigns/:id` | 캠페인 상태와 포스터 확인, 수정 |
| QR 스캔 | `/qr-scan` | 손님의 쿠폰 QR을 스캔해 사용 처리 |
| 가게 · 리포트 | `/store`, `/store/analytics` | 가게 정보와 노출 · 발급 · 사용 현황 |

## 폴더 구조

```
src/
├── app/            # 라우터
├── pages/          # 주소 하나에 대응하는 화면
├── features/
│   ├── login/          # 점주 로그인
│   ├── signup/         # 입점 신청 단계
│   ├── home/           # 홈 대시보드
│   └── campaign/       # 캠페인 목록, 등록, 상세, 포스터 미리보기
├── components/     # 여러 기능이 함께 쓰는 컴포넌트
├── hooks/          # 여러 기능이 함께 쓰는 훅
├── layout/         # 화면 틀
├── api/            # 서버 요청 함수와 mock 데이터
└── auth/           # 로그인 상태와 접근 제어
```
